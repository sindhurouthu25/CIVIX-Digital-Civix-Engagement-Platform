# CIVIX – Digital Civic Engagement & Petition Platform

CIVIX is a MERN-based web application developed during the Infosys Springboard Internship to improve digital civic participation and transparency.

The platform enables citizens to:
- Create and manage petitions
- Participate in polls
- Track civic issues
- Engage with government officials digitally

---

## 🚀 Features

### 🔐 Authentication
- User Registration & Login
- Role-based access (Citizen/Admin)

### 📢 Petition Management
- Create petitions
- Sign petitions
- Track petition status

### 🗳️ Polling System
- Poll creation by officials
- Citizen voting
- Real-time poll results

### 📊 Dashboard & Reports
- Governance dashboard
- Analytics and reporting
